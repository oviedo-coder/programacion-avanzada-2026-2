💡 ¿Qué vas a instalar y para qué?

Vamos a construir un e-commerce completo: el backend (la lógica y los datos) en Spring Boot, y el frontend (lo que ve el usuario) en Angular. Para eso necesitas cinco herramientas, cada una con un trabajo distinto:

  • JDK: le permite a tu computador entender y ejecutar código Java.
  • IntelliJ IDEA: el editor donde vas a escribir el backend.
  • MariaDB: la base de datos donde se guarda la información del proyecto.
  • Git: para guardar y compartir el código durante el semestre.
  • Visual Studio Code: el editor para el frontend en Angular.

🧠 Analogía: si el proyecto fuera una casa, el JDK es la electricidad que hace que todo funcione, IntelliJ y VS Code son tus herramientas de construcción, y MariaDB es donde guardas todos los documentos importantes.

⚙️ JDK 21

Se instala primero — todo lo demás depende de él.

  1. Entra a Adoptium — Temurin 21.
  2. Elige Windows, arquitectura x64, y descarga el .msi.
  3. Instálalo marcando la opción "Set JAVA_HOME variable" si aparece.
  1. Entra a Adoptium — Temurin 21.
  2. Elige macOS y tu arquitectura (aarch64 en Apple Silicon, x64 en Intel).
  3. Descarga el .pkg e instala con el asistente.
  1. Entra a Adoptium — Temurin 21 o instala desde terminal:
sudo apt update
sudo apt install temurin-21-jdk
java -version
javac -version

✅ Ambos comandos deben mostrarte la versión 21.

🖥️ IntelliJ IDEA

Usamos la versión Ultimate (no Community) — tiene soporte para Spring Boot y es gratuita para estudiantes.

  1. Descárgala desde JetBrains — IntelliJ IDEA, elige tu sistema operativo y la versión Ultimate.
  2. Crea una cuenta en JetBrains Account con tu correo institucional.
  3. Solicita la licencia gratuita de estudiante en jetbrains.com/shop/eform/students.
  4. Instálala y abre sesión con tu cuenta de JetBrains.

💡 Si no habías instalado el JDK antes de este paso, no pasa nada: al crear tu primer proyecto puedes usar New Project → JDK → Download JDK... y elegir la versión 21 desde ahí mismo.

🗄️ MariaDB

Aquí va a vivir toda la información del proyecto (usuarios, productos, compras).

  1. Descárgala desde mariadb.org/download, versión 12.
  2. Durante la instalación, define una contraseña para el usuario root — anótala, la vas a necesitar todo el semestre.
mariadb --version
mariadb -u root -p

✅ Si entras al prompt MariaDB [(none)]>, quedó lista.

nota

En Mac, si el instalador de la web te da problemas, puedes instalarla con Homebrew: brew install mariadb y luego brew services start mariadb.

🔧 Git

Lo vamos a usar para guardar y compartir el código del proyecto durante todo el semestre.

  1. Descárgalo desde git-scm.com/downloads y elige tu sistema operativo.
  2. Instala con las opciones por defecto.
git --version

✅ Debe mostrarte un número de versión.

md [6]

🎨 Visual Studio Code

El editor para la parte de frontend (Angular).

  1. Descárgalo desde code.visualstudio.com/download.
  2. Instala las extensiones: ESLint, Prettier y Angular Language Service (ícono de cuadritos en la barra lateral).
