💡 ¿Qué son Git y GitHub?

Git guarda un historial de todos los cambios de tu código — como el "historial de versiones" de Google Docs, pero para programación. GitHub es la página web donde ese historial vive también en internet, para que todos en el grupo lo vean y trabajen sobre lo mismo.

🔁 El ciclo esencial

Estos 4 comandos son el 90% de lo que vas a usar todo el semestre. Siempre en este orden:

1git pull — traes lo último que subieron tus compañeros, antes de empezar a trabajar.

2git add . — marcas tus cambios como "listos para guardar".

3git commit -m "mensaje claro" — guardas esos cambios con una nota explicando qué hiciste.

4git push — subes tus cambios a GitHub, para que todos los vean.

💡 Piénsalo como enviar un correo: add es escribir el mensaje, commit es ponerle asunto, push es darle enviar.

✅ Ejercicio guiado paso a paso

Vamos a hacerlo juntos en clase, cada quien en su propio computador:

  1. Entra a github.com con tu cuenta y crea un repositorio nuevo llamado practica-git-tunombre (público, con README).
  2. Copia la URL del repo (botón verde Code).
  3. En tu terminal, clónalo: 
    git clone URL-QUE-COPIASTE
  4. Entra a la carpeta que se creó: 
    cd practica-git-tunombre
  5. Agrega una línea al README: 
    echo "Mi primera práctica de Git" >> README.md
  6. Ahora el ciclo completo: 
    git add .
git commit -m "Mi primer commit"
git push
  7. Entra a tu repo en GitHub (en el navegador) y confirma que el cambio ya aparece ahí.
